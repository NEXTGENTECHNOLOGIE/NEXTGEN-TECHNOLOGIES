Installation de votre agent

Choisissez votre système d'exploitation. Le script d'installation sera généré automatiquement et téléchargé sur votre machine.

Important : Le lien d'installation est valable 24 heures. Si vous avez besoin d'un nouveau lien, contactez-nous.

🖥️

Windows PC

Pour les ordinateurs de bureau et portables Windows

🗄️

Windows Server

Pour les serveurs Windows

🐧

Linux

Ubuntu, Debian, CentOS, Rocky Linux

🍎

macOS

MacBook, iMac, Mac mini

📋 Comment ça marche ?

  1. Cliquez sur le bouton correspondant à votre système
  2. Le script d'installation se télécharge automatiquement
  3. Exécutez le script (Windows : clic droit → "Exécuter avec PowerShell" | Linux/macOS : sudo bash script.sh)
  4. L'agent s'installe en quelques secondes et apparaît dans votre tableau de bord Tactical RMM
